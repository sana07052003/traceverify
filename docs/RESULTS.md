## Does the image help?

| Setting | n | Accuracy | Macro-F1 |
|---|---|---|---|
| multimodal all | 2001 | 49.0% | 0.462 |
| text only all | 2001 | 48.9% | 0.460 |
| multimodal image subset | 979 | 42.2% | 0.361 |
| text only image subset | 979 | 42.0% | 0.356 |
| image only logreg image subset | 979 | 41.6% | 0.372 |

The image changes the deep model's prediction for **4.9%** of image claims.
